# BIGバスターズ：北千住編・上野編・秋葉原編

北千住駅前のアーケード、青い常磐線の車内、上野の居酒屋通りと駅前広場、秋葉原駅のホームと駅前広場を舞台にした、スマホ向けの3D協力アクションです。小さなもののけ4体で、トバトーバ（北千住編）、指揮官ヨシノシン（上野編）、星・中とオガ・カエ（秋葉原編）を鎮めます。

- **遊ぶ（ログイン不要・協力プレイ可）**：https://koyoy1016-gif.github.io/games/tobatoban/
- 横画面で遊ぶゲームです（縦持ちでも画面を90度回して表示）
- キャラクター・技名・台詞・BGM・効果音・3Dモデル・UI・アイコンはこの作品用の新規制作です。メニューの配置はブロスタを参考にしていますが、絵・アイコン・模様は本作のものです
- 仕様の正本：`data/spec-v5.txt`（v5）と `data/spec-v6-ui-balance.txt`（v6：UI改修・バランス調整）。指示書と依頼のメッセージが食い違う所は依頼を優先（下の「v6」）

## 画面と遊びの流れ（v6）

1. **ログイン前**：大きな3択「ログイン」「新しくアカウントを作る」「ログインせずに遊ぶ」。ID・パスワードは押したあとに開く入力欄で。左下の歯車＝設定、LINEの注意文、「セーブデータはサーバーに保存されます」
2. **ホーム**（ログイン後もゲストも同じ）：中央に次に出動する4体（3D・台座つき・名前／Lv／あなた・AI）、左に「編成」「協力プレイ」「ガチャ」「フレンド」、上にプレイヤー名／ID・セーブ・アカウント・チケット、右下にステージ欄と黄色い「出動」。ステージを選んだだけでは始まらない
3. **編成**：色付きのカード（顔と上半身・左下にLvとEXPバー・右にS〜Dランク）を横スワイプ。上で「どの枠（P1〜P4）に入れるか」と並べ替え（レベル順／ランク順／ちから順／最近使った順）、持ち物（アイテム2つ）
4. **キャラ詳細**：左に名前・ランク・役割・Lv・区間EXP（あと○EXP）・短い説明、中央に大きな3D（左右ドラッグで回転）、右に HP・ちから・ようりょく・まもり と A・X・Y・必殺の要点（くわしくは「ⓘ」）。右上の装備スロット1・2から12種を選ぶ（差分を右の能力に表示）。下の「このキャラを選ぶ」で枠へ
5. **ステージ選択**：6ステージの大きなカードを横スワイプ。未解放は鍵。選ぶとホームへ戻る
6. **協力プレイ**：「ルームを作る」「パスワード（合言葉）で参加」→ ホームの4枠に参加者が入る（足りない分はAI）。出動はホストだけ
7. **戦闘**：北千住 → 常磐線 → 居酒屋通り → ヨシノシン → （秋葉原へ進む・徒歩演出）→ 秋葉原駅ホーム → 駅前広場
8. **フレンド**（ホーム左の「フレンド」。公開ページでログイン中だけ）：自分のフレンドコード（例 `K7Q4-2MPX`）をコピー／「招待リンクを送る」→ 相手がコードを入れるかリンクを開いてログイン →「申請」→ こちらが「承認」。一覧に オンライン／ルーム○○で募集中／プレイ中／最終○分前 が出て、募集中のフレンドには「参加」で合言葉なしに入れる。ルームを作っている間はオンラインのフレンドへ「招待」を送れ、相手のホームに通知（参加・×）が出る

## フレンド（なぜログインIDをフレンドIDにしないか）

- ログインIDは 1〜10000 の連番で、**パスワードと組のログイン情報**です。フレンドIDに使うと、IDを人に見せることになり、番号を順に試すだけで知らない人へ申請を送れてしまいます
- そこで、アカウントごとに **ランダムな8文字のフレンドコード**（`0 O 1 I L` のような見まちがえる字は使わない・約8.5×10¹¹通り）を別に作ります。コードを知っている人だけが申請でき、一覧から探すことはできません。教えてもログインはできません
- 申請は「申請（req）→ 相手の承認（ok）」の2段階。相手からも申請が来ていれば、申請した時点でフレンドになります。フレンドと申請は合わせて50人まで。どちらからでも解除できます
- 状態（なまえ・先頭キャラ・最後に見えた時刻・募集中のルーム）は**フレンドだけが読めます**。2分ごとと、状態が変わったときに知らせ、5分更新がなければオフライン扱い。ログアウトで即オフライン
- 一覧は読み込みだけ（常時接続はしない）。フレンド画面を開いている間は20秒ごと（相手の状態も読む）、ほかの画面では90秒ごと（申請と招待だけ）、戦闘中は読みません。招待は5分有効
- Firestore の無料枠（1日に読み取り5万・書き込み2万）の目安：1人が1時間開いていると、書き込み約30回、読み取りは「フレンド数×40回」ほど（ホームにいる間）。フレンド画面を開きっぱなしにすると増えます
- **使うには `firestore.rules` を Firebase コンソール（Firestore → ルール）に貼りつけて公開する必要があります。** 古いルールのままだと、フレンド画面に「サーバーの設定を確認してください」と出ます（ログイン・セーブは今まで通り使えます）
- ログインしていないとき・claude.ai の中（端末内セーブ）では使えません

## v6 で変えたこと（UI改修・バランス調整）

### 依頼のメッセージを優先した所（指示書と食い違い）
- オガ・カエ **HP5,000**、星・中 **HP10,000**（指示書は4,000／8,000）。ちから・ようりょく600、まもり 星中170・オガカエ150 は指示書どおり
- オガ・カエの一撃は **約150〜200**：技ごとに幅（紅扇たたき150〜175・水杖なぎ155〜180・灯りの息150〜170・水環めぐり160〜185・紅花おとし175〜200、まもり100の相手への目安）の中で1発ごとにランダム。まもりの高いキャラ・ガード・Lv差補正では下がる
- **X・Yのため攻撃は最大ためまで0.5秒**（旧1.0秒・50%短縮）。指示書は「ためは変えない」だが依頼を優先
- 星・中が復活するときのHPは指示書どおり4,000のまま（最大HPは10,000）

### バランス（指示書どおり）
- トバトーバ（表示名を変更・内部IDはそのまま）：HP20,000・ちから/ようりょく250（0.7倍を出現時に1回だけ→実効175）・まもり120。千住大巡行の横断は通常3回・覚醒（HP1/3以下）6回。覚醒中は赤いオーラと体の赤い発光
- ヨシノシン：HP22,000・500/500/150。睡眠16,500/11,000/5,500、予告17,600/12,100/6,600、失敗は22,000へ全回復。三十六光の番号表示を消した（床の予兆・タイミングは同じ）
- ヨシノシンの部下：歩く速さ50%（剣・パンチ1.3、ビーム1.2m/秒。電車・通り・上野）。上野では部下の剣・パンチ・ビームの範囲が本体に重なると本体に当たる（1攻撃1回・手前の味方で止まる攻撃は背後へ通らない・バリア中は0）
- Lv差補正の基準：ヨシノシン40・秋葉原ホーム50・駅前広場60（推奨Lvの表示も同じ値）
- 全60体のA通常攻撃の時間を70%（三連0.105/0.315/0.595秒・硬直0.805秒など）
- 移動を同じ向きへ1秒続けると自動ダッシュ（人の操作のみ・止まると解除・息切れは通常どおり）
- **G玉**（旧・重玉）：有効戦闘30秒ごと。拾うと10秒だけ ちから・ようりょく×2（金色の炎のオーラ・仲間カードに残り秒）。旧「強化必殺」とボタンは廃止

## セーブと公平性（正直な注意）

- **このゲームのセーブは改ざんを防げません。** 端末内版（localStorage）は持ち主がブラウザで書き換えられますし、Firebase版も「本人だけが自分のセーブを読み書きできる」ルールで、セーブの中身（所持・EXP・チケット・勝利数・ガチャ結果）はブラウザが計算して丸ごと書き込みます。信頼できるサーバーで報酬や抽選を確定する仕組みはありません。友だちどうしのローカル試遊として扱ってください
- できていること：同じ戦闘IDの報酬は一度だけ、同じ抽選依頼IDのガチャは一度だけ（再送・連打・演出スキップで増えない）、移行を2回しても増減しない、パスワードそのものは保存しない
- 通信の版（`tb6`）が違う端末どうしは同じ部屋に入れない（v5の秋葉原・重玉などの状態を古い版が読み違えないように）
