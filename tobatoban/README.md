# BIGバスターズ：北千住編・上野編・秋葉原編

北千住駅前のアーケード、青い常磐線の車内、上野の居酒屋通りと駅前広場、秋葉原駅のホームと駅前広場を舞台にした、スマホ向けの3D協力アクションです。小さなもののけ4体で、トバトーバン（北千住編）、指揮官ヨシノシン（上野編）、星・中とオガ・カエ（秋葉原編）を鎮めます。

- **遊ぶ（ログイン不要・協力プレイ可）**：https://koyoy1016-gif.github.io/games/tobatoban/
- 横画面で遊ぶゲームです（縦持ちでも画面を90度回して表示）。拠点・編成・ガチャ・図鑑は縦画面でも読めます
- キャラクター・技名・台詞・BGM・効果音・3Dモデル・UIはこの作品用の新規制作です。街は実在の場所を参考にした架空の再構成で、実在店舗のロゴは使っていません
- 仕様の正本：`data/spec-v5.txt`（制作プロンプト v5）。ゲーム名だけは依頼に合わせて「BIGバスターズ」（仕様書の「四人でバスターズ」から変更）

## 起動手順

| やりたいこと | 方法 |
|---|---|
| 遊ぶ | 上のURLをスマホで開く →「はじめる」→ 拠点の「出動」 |
| 手元で動かす | リポジトリの直下で `python3 -m http.server 8000` → `http://localhost:8000/tobatoban/` |
| ソースを直したあと | `python3 tobatoban/src/build.py`（`src/` を結合して `index.html` を作る。`index.html` は直接編集しない） |
| 一覧を作り直す | `node tobatoban/tools/dump-values.mjs`（`VALUES.md`）・`node tobatoban/tools/dump-chars.mjs`（`CHARACTERS.md`） |

## 遊びの流れ

1. **タイトル**：はじめる／ガチャ／設定。ログインしなくても遊べる（ログインするとセーブ）
2. **拠点**：出動・編成・装備・ガチャ・図鑑・設定
3. **出動**：① キャラ選択（4体）→ ② ステージ選択（章タブ「北千住編」「上野編」「秋葉原編」）。ステージ画面から「キャラ選択へ戻る」で戻れる
4. **北千住編**：通り → 祭り広場でトバトーバン
5. **上野編**：常磐線（235体・推奨Lv20）→ 上野の居酒屋通り（30体）→ 準備画面 → ヨシノシン（推奨Lv40）。電車クリアで通り、通りクリアでボスが解放され、以後は直接挑戦できる
6. **秋葉原編**（ヨシノシン初勝利で解放）：上野の勝利後「秋葉原へ進む」→ 4体を編成 → 上野→御徒町→秋葉原の徒歩演出（15秒・スキップ可）→ 秋葉原駅ホーム（オガ・カエ）→ 準備画面 → 秋葉原駅前広場（星・中＋オガ・カエ）
7. **結果**：固定率のEXP（ソロ：P1枠100%・ほか80%／マルチ：人間100%・AI補充80%。協力ボーナスなし）、レベルアップ、チケット

## v5 で実装したこと

### 修正
- **ガチャを開くと戻れなくなる不具合**：閉じるといつもタイトルへ戻る（以前の `gcBack`/`loginBack` を使い回さない）。未ログインで「ログインして引く」→ログイン成功でガチャへ戻る（1回だけの行き先）、取消でもガチャへ戻る。閉じるたびに3Dの描画を破棄してキャンバスを作り直す（2回目に開くと真っ黒になる問題も解消）
- ガチャ：開封前のカプセルにランク文字を描かない・率の一覧を出さない・結果の文字は3D画面の下（重ならない）
- 出動の順番を「キャラ選択 → ステージ選択」に変更

### 電車・居酒屋通り・ヨシノシン
- 常磐線：235体・8イベント（前後の車両から）。車内の生存上限40、あふれた分は前後の待機列。撃破○/235と増援の方向を表示。上野の手前で敵が残っていれば「上野進入待ち」
- 部下3種（HP200・剣/パンチ/ビーム）。同時に攻撃権を持つのは近接4・ビーム2（権利は予兆開始から最短周期のあいだ保持して交代）
- 上野の居酒屋通り：提灯と暖簾の通りで30体（電車の部下×1.25）。暖簾の結界3つ
- ヨシノシン：HP30,000・ちから600・ようりょく650・まもり182、身長5.92m（×1.85。判定は拡大しない）。天蓋乱射・三十六光（番号つきの落下）、部下丸投げ五十連（22,500と7,500で）、30秒ごとの包囲動員15体（生存上限100）、3段階の睡眠チャージ（22,500→2,500／15,000→3,500／7,500→4,000・被ダメージ×2.25・HPロック・失敗は全回復で1段目から）
- Lv補正（上野・秋葉原だけ）：推奨Lv未満は 与ダメージ×0.95^差・被ダメージ×1.04^差、以上は上限つきで有利

### 重玉・装備・閃光銃
- 重玉：有効戦闘50秒ごとに1つ（壁で跳ねる・10秒で消える・残り3秒は点滅と秒数）。拾うと「重玉」ボタンで必殺の効果量2倍
- 装備12種（剛力の腕輪・霊光の鈴・守護のお守り・命結びの勾玉 × 青/紫/金）。電車クリア前は1枠、クリア後は2枠。拠点の「装備」から
- 閃光銃800：1戦闘1発、最初に当たった敵1体へ固定800

### 秋葉原編
- 秋葉原駅ホーム（安全幅18m×26m）：オガ・カエ（各HP4,000）を両方倒すと勝ち
- 秋葉原駅前広場（28m四方）：始まりに星と中が倒れたオガ・カエを一度だけ起こす（各4,000）。星・中（各8,000）は片方が倒れてから15秒以内にもう片方も倒すと勝ち。間に合わなければ倒れた方だけHP4,000で復活。2〜4人で結ぶ図形の必殺（二点結び・三角結界・四角結界）。通常攻撃は全体で同時2人まで
- 見た目の大きさ：**星・中は2.0倍、オガ・カエは1.5倍**（依頼による変更。HP・能力・当たり判定の半径は変えていない）
- HUD：4人の体力（星・中は太いバー、オガ・カエは細いバー）、倒れた双子の「復活まで○秒」、15秒の残り時間、図形の名前、ミニマップ
- 報酬：ホーム 勝20,000／負5,000、広場 勝70,000／負10,000

## セーブと公平性（正直な注意）

- **このゲームのセーブは改ざんを防げません。** 端末内版（localStorage）は持ち主がブラウザで書き換えられますし、Firebase版も「本人だけが自分のセーブを読み書きできる」ルールで、セーブの中身（所持・EXP・チケット・勝利数・ガチャ結果）はブラウザが計算して丸ごと書き込みます。信頼できるサーバーで報酬や抽選を確定する仕組みはありません。友だちどうしのローカル試遊として扱ってください
- できていること：同じ戦闘IDの報酬は一度だけ、同じ抽選依頼IDのガチャは一度だけ（再送・連打・演出スキップで増えない）、移行を2回しても増減しない、パスワードそのものは保存しない
- 通信の版（`tb6`）が違う端末どうしは同じ部屋に入れない（v5の秋葉原・重玉などの状態を古い版が読み違えないように）

### 実測（2026年10月・AIだけの試走。人が遊んだ結果ではありません）

P1は「人が操作」扱いで能力100%（入力はAI）、P2〜P4はAI能力90%。編成はコゲマル・ホシスズメ・ブリキドン・モミジ翁。

| 場面 | 設計の目標 | 試行 | 勝ち | 時間（演出を除く） |
|---|---|---:|---:|---|
| 常磐線・Lv20 | 6〜10分 | 3 | 3 | 3分18秒〜3分28秒（被弾146〜180・気絶0〜2） |
| 居酒屋通り・Lv30 | － | 2 | 2 | 36〜40秒 |
| ヨシノシン・Lv40（装備なし・銃なし） | 標準編成で全段階を突破 | 5 | 1 | 勝ち13分18秒。ほかは全滅2（1分38秒・7分10秒）・20分で時間切れ2（睡眠3段目の失敗で全回復） |
| ヨシノシン・Lv40（紫の腕輪＋お守り・2体が閃光銃） | 同上 | 2 | 2 | 6分41秒〜6分49秒 |
| ヨシノシン・Lv50 | － | 2 | 2 | 8分02秒〜8分50秒 |
| ヨシノシン・Lv60 | － | 2 | 2 | 7分51秒〜8分47秒 |
| 秋葉原駅ホーム・Lv60 | 2〜3分 | 2 | 2 | 55秒〜1分02秒 |
| 秋葉原駅前広場・Lv60 | 3〜6分 | 2 | 2 | 3分55秒〜4分38秒（双子の15秒失敗0回） |

**目標とのずれ（数値は仕様のまま変えていません）**
- 電車：走行時間（区間長・最高速・停車8秒は仕様で維持）で戦闘時間がほぼ決まり、AIでは約3分20秒。6〜10分にするには区間長や停車時間の見直しが必要です
- 電車の攻撃権：最初は「攻撃動作のあいだだけ権利を持つ」実装で、Lv20〜40のAIが開始10〜20秒で全滅しました。「予兆開始から最短周期（剣3.2秒・拳3.5秒・ビーム5秒）のあいだ権利を持つ」へ変えて上の結果です（上野の部下にも同じ規則）
- ヨシノシンLv40：装備・銃なしのAIでは勝率が低く（5回中1回）、ほとんどが睡眠2段目の手前（HP約19,000）で部下のビームと天蓋乱射・指令連掌に押し切られます。装備と閃光銃があれば2回とも6分台で勝ちました。人が回避すれば結果は変わるはずですが未計測です
- 秋葉原駅ホーム：AIでは約1分で、目標の2〜3分より短い
- 図形の必殺はAI試走で二点結びが多く（例：線9・三角1・四角2）、四角は少なめ
- 協力プレイ（2〜4人）での勝率・時間はまだ測っていません
