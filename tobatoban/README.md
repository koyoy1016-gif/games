# 四人でバスターズ：北千住編・上野編

北千住駅前のアーケード通り（車なし・架空に再構成）と、青い常磐線の車内、上野駅前の広場を舞台にした、スマホ向けの3D協力アクションです。小さなもののけ4体で、北千住編では大看板の付喪神「トバトーバン」、上野編では部下を人形のように操る指揮官「ヨシノシン」を鎮めます。

- **遊ぶ（ログイン不要・協力プレイ可）**：https://koyoy1016-gif.github.io/games/tobatoban/
- **横画面で遊ぶゲームです。** スマホを縦に持っていても、画面全体を90度回して横向きで表示します。拠点・編成・ガチャ・図鑑は縦画面でも読めます
- キャラクター・技名・台詞・BGM・効果音・3Dモデル・UIはこの作品用の新規制作です（既存作品の素材は使っていません）。技の種類は参考作品の攻撃・防御・回復の型に限っていますが、名前・数値・組み合わせ・新ボスの演出は本作独自です

## 起動手順

| やりたいこと | 方法 |
|---|---|
| 遊ぶ | 上のURLをスマホで開く →「はじめる」→ 拠点の「出動」 |
| 手元で動かす | リポジトリの直下で `python3 -m http.server 8000` → `http://localhost:8000/tobatoban/` |
| ソースを直したあと | `python3 tobatoban/src/build.py`（`src/` を結合して `index.html` を作る。`index.html` は直接編集しない） |
| 追加50体のデータを作り直す | `python3 tobatoban/tools/gen-roster.py`（`data/nightwatch-v2-game-data.json` → `src/roster_data.js`） |
| 一覧を作り直す | `node tobatoban/tools/dump-values.mjs`（`VALUES.md`）・`node tobatoban/tools/dump-chars.mjs`（`CHARACTERS.md`） |

three.js は CDN（jsDelivr, r160）から読み込みます。P2P通信のライブラリ `trystero-nostr.js` は同じフォルダに置いています。

## 遊びの流れ

1. **タイトル**：はじめる／ガチャ／設定（ログインしなくても遊べる。ログインするとセーブされる）
2. **拠点**：出動・編成・ガチャ・図鑑・設定
3. **出動**：章タブ「北千住編」「上野編」。上野編の中に「常磐線（推奨Lv20）」と「上野駅前 ヨシノシン（推奨Lv40）」。いまの平均Lvを表示し、低くても挑戦できる
   - 常磐線はトバトーバンを1回倒すと解放。ヨシノシンは電車を1回クリアすると解放（以後は直接挑戦できる）
4. **北千住編**：通り（札小僧2波）→ 祭り広場でトバトーバン戦
5. **上野編・電車**：北千住→南千住→三河島→日暮里→上野。9つのイベントで合計135体（下の表）。全員倒すと上野に着き、電車の報酬（EXP20,000）を確定 → **準備画面**（このままヨシノシンへ／編成／拠点へ）
6. **上野編・ボス**：上野駅前の広場（34m×28m）でヨシノシンと部下36体。負けても「ボスから再挑戦」（電車をやり直さなくてよい）
7. **結果**：キャラごとのEXP（人が操作100%・AI80%・控え0%、協力人数のボーナス）とレベルアップ、チケットの進み具合

## 実装済み（制作プロンプト v3）

### 名前・章
- ゲーム名「四人でバスターズ」、章名「北千住編」「上野編」、ボス名「ヨシノシン」（敵名・広告・説明の「ヨシノシ」もすべて統一）。保存キーは変えていないので以前のセーブはそのまま使える

### 育成（Lv1〜99）
- 能力：HPの初期値＝四捨五入(Lv99値×0.6)、ほかは×0.65。能力(L)＝初期値＋floor((Lv99値−初期値)(L−1)/98)。AIが動かすキャラは HP・ちから・ようりょく・まもりが各90%（切り捨て）・移動90%
- EXP：ランクごとの整数表（D/C 累計1,288,605・B 1,480,611・A 1,676,610・S 1,880,599）。JSONの表をそのまま正本として埋め込み、5,940行を検査
- 報酬：北千住 勝10,000／負2,500、電車 勝20,000／負5,000、上野 勝50,000／負7,000。人が操作したキャラ100%・AI80%・控え0%。協力は ×(1+min(0.3, 0.1×(人数−1)))、切り捨て。ソロで操作を交代したキャラは「0.8＋0.2×人が操作していた割合」
- 戦闘ID（報酬）・抽選依頼ID（ガチャ）で一度だけ確定（再送・二重押しで増えない）

### 60体・編成・図鑑
- 既存10体（公開版のID）＋追加50体（D10体は最初から所持・C〜Sの40体はガチャ）。役割は アタッカー／タンク（壁）／サポーター／ヒーラー の4つ＋得意タグ
- 追加50体は全員に専用の3Dモデル（身長・頭身を仕様どおりに個別設定）と、A・X・Y・必殺（10種類の行動テンプレートから。回避・ため・射撃・風/氷妖術・誘い打ち・ガード・反射ガード・短い無敵・爆弾・地雷・回復・回復陣・強化・能力低下）
- 編成：4枠（P1はあなた、P2〜P4は「AI：能力90%／EXP80%」）、役割の内訳、並び替え（レベル高い順〈既定〉・ランクS→D・レベル低い順・入手が新しい順）、絞り込み（ランク・役割・得意・名前・NEW・所持。同じ種類はOR、種類どうしはAND。アカウントごとに保存）、詳細（Lv1・いま・AI時・Lv99の能力、EXPバー、技の説明）、おすすめ編成（押したときだけ）
- 図鑑：60体（未所持は影）

### ガチャ（通常ガチャ）
- チケット：トバトーバン3勝で1枚、ヨシノシン2勝で1枚（貯めておける・自動では引かない）。電車・敗北・部下の撃破では進まない
- 未所持の1体ごとに重み C3.5・B3.5・A2.2・S0.8（最初は35/35/22/8%）。Dは出ない。引いたキャラは必ず Lv1・EXP0。40体すべて入手後は 1枚＝EXP10,000 と交換
- 3Dのカプセルマシン（ハンドルを90度回す→転がる→落ちる→ランク別の開き方 C1.6/B2.0/A2.6/S3.2秒・緑/青/紫赤/金・文字と模様）、スキップ可。結果は抽選を確定してから演出（スキップ・切断で引き直しにならない）。チケット0枚でも入口・確率・演出見本を見られる

### 常磐線（全135体・推奨Lv20）
| イベント | 発生 | 数 | 入り方 |
|---|---|---:|---|
| p1 | 乗車して戦闘開始 | 10 | 2号車にいる |
| p2 | p1の10体を全部倒す | 15 | 1号車から |
| p3 | p2の15体を全部倒す | 20 | 1号車から |
| station_minami | 南千住に停車してドアが開く | 15 | ホーム側のドア |
| mid_1 | 南千住→三河島の走行距離50% | 10 | 1号車から |
| station_mikawa | 三河島に停車してドアが開く | 15 | ホーム側のドア |
| mid_2 | 三河島→日暮里の走行距離50% | 15 | 1号車から |
| station_nippori | 日暮里に停車してドアが開く | 25 | ホーム側のドア |
| mid_3 | 日暮里→上野の走行距離50% | 10 | 1号車から |

- 初期3波は撃破で、駅は停車で、区間中央は走行距離の50%通過で、それぞれ一度だけ（49%→52%へ飛んでも一度、50%に居続けても増えない）。駅の敵を倒しても初期波は進まない
- 車内は同時20体まで（あふれた分は1号車の待機列。ドアが閉まるまでに乗り切れなかった分も前の車両で待つ）。外側のドアは走行中に開かない
- 部下3種（各イベントを近接60%・ビーム25%・防御15%に最大剰余法で分ける）：近接 HP110/ちから120/ようりょく80/まもり45・物理60・予兆0.65秒/周期3.2秒、ビーム HP85/60/150/35・妖術70・1.1秒/4.5秒（幅0.7mの直線で左右に逃げ幅が残る）、防御 HP160/135/80/70・物理60・0.8秒/4.0秒（殴られる・殴られそうになると最大2秒だけ×0.7のガード、再使用5秒）。ダメージは共通式（以前の「防御を無視する固定50〜80」は削除）
- 同時に攻撃を始めるのは近接・防御4体＋ビーム1体まで（20体全員は動き続け、攻撃する権利だけを交代）。連結部では左右に寄って通路を塞がない
- 上野に着く条件：全イベント発生済み・待機0・車内0。敵が残っている間は上野の手前を走り続け「車内の敵を倒すと上野に到着」と表示
- HUD：路線図・次の駅・撃破○/135・車内の数・待機の数

### 上野駅前・指揮官ヨシノシン（推奨Lv40）
- 舞台：赤茶色のタイルの広場（x±17・z0〜28）、奥に駅舎と大きな庇・時計、左奥の高架に青い常磐線、案内板、外側の街灯、遠景の並木。入口側と左右に回り込みの余白
- ヨシノシン：身長3.2m・約5頭身。背を丸めて肩を前へ、頭を傾けた細い笑い、灰紫の長い上着、指揮札、左右で長さの違う袖。HP26,000・ちから400・ようりょく450・まもり135。全属性×1
- 登場（約3.2秒）：36体が6列に並ぶ奥で指を鳴らし、もたれるように反る → 通常カメラに戻ってから最初の予告。全員が同時に前進
- 技：采配三連霊光（3方向の光弾）・指令連掌（近づいた味方へ。最後の0.25秒は向き固定）・一斉決裁スタンプ（中央へワープして半径4.5m）・号令四連照射（前方横並び4本／周囲4本／追跡3発を交代、1回の一斉射で1人1ヒット）・後方指揮ワープ・追加動員（8体以下で6体）・完全指揮バリア（射撃部下のビームを2回本体へ通すと破壊、1本は1回、射撃部下がいないと使わない、最大8秒）・部下丸投げ二十連（HP75%・25%で各1回、生存20体以下になってから必ず20体、着弾は1回の投げで1人2回まで、全回復しても使用済みは戻らない）・30分睡眠チャージ
- 直接攻撃どうしの開始は最低3秒あけ、「指揮・待機・位置調整」をはさむ。部下の後ろに陣取り、追い回さない
- 部下：最初36体（近接24・防御8・射撃4）、生存上限40、同時に攻撃するのは近接・防御4＋射撃2。投げられる部下 HP75。部下は「ヨシノシンを小さくした妖怪人形」（身長0.8〜0.95m）
- 30分睡眠チャージ：HP50%を上からまたぐと発動（またいだ一撃の余剰だけを計上）。10秒・4体合計3,000ダメージ（被ダメージ×2、HPとカウンターは同じ実ダメージ）。成功→4秒ダウン・以後は眠らない。失敗→最大HPに戻り、また50%で再判定。睡眠中は部下が止まり、予告前の攻撃は消える。HP55%で「半分になる前に接近して必殺を準備」と予告。画面中央に「10秒以内に4体合計3,000ダメージを与えろ！」・残り秒・○/3,000のバー
- 上野だけのLv補正：開始時の4体の平均Lv（切り捨て）Pで、与ダメージ×clamp(1+0.02(P−40), 0.75, 1.25)、被ダメージ×clamp(1−0.015(P−40), 0.80, 1.20)。途中の操作交代では変わらない。出動画面とHUDに表示
- 電車から続けて挑むときは HP・スタミナ全回復・気絶解除・必殺ゲージは最低50%、アイテムは電車の終わりの所持数を引き継ぐ
- HUD：ボス名とHP、部下○/40、バリアの誘導回数と残り秒、Lv補正、睡眠チャージのパネル。ミニマップは広場全体

## セーブと公平性（正直な注意）

- **このゲームのセーブは改ざんを防げません。** 端末内版（localStorage）は持ち主がブラウザで書き換えられますし、Firebase版も「本人だけが自分のセーブを読み書きできる」ルールで、セーブの中身（所持・EXP・チケット・勝利数・ガチャ結果）はブラウザが計算して丸ごと書き込みます。信頼できるサーバーで報酬や抽選を確定する仕組みはありません。友だちどうしのローカル試遊として扱ってください
- できていること：同じ戦闘IDの報酬は一度だけ、同じ抽選依頼IDのガチャは一度だけ（再送・連打・演出スキップで増えない）、移行を2回しても増減しない、パスワードそのものは保存しない
- 通信の版（`tb5`）が違う端末どうしは同じ部屋に入れない（上野・追加キャラの状態を古い版が読み違えないように）
