# 北千住もののけ夜警隊：トバトーバン戦

北千住駅前のアーケード通り（車なし・架空に再構成）と祭り広場を舞台にした、スマホ向けの3D協力アクションです。小さなもののけ4体で、巨大な付喪神「トバトーバン」を鎮めます。

- **遊ぶ（ログイン不要・協力プレイ可）**：https://koyoy1016-gif.github.io/games/tobatoban/
- **横画面で遊ぶゲームです。** スマホを縦に持っていても、画面全体を90度回して横向きで表示します（claude.aiのアプリなど、画面が自動で回転しない環境でも横画面で遊べます）。スマホを左に倒して持ってください。逆向き・縦画面レイアウトは設定で切り替えられます
- キャラクター・技名・台詞・BGM・効果音・3Dモデル・UIはこの作品用の新規制作です（既存作品の素材は使っていません）

## 起動手順

スマホでURLを直接タップして開くと画面がブレることがあるため、URLをメモ帳などに貼り付けてから開くことをおすすめしています（ログイン画面と協力プレイ画面にも表示）。

| やりたいこと | 方法 |
|---|---|
| 遊ぶ | 上のURLをスマホで開く。「ひとりで遊ぶ」か「協力プレイ」 |
| 手元で動かす | リポジトリの直下で `python3 -m http.server 8000` → `http://localhost:8000/tobatoban/` |
| ソースを直したあと | `python3 tobatoban/src/build.py`（`src/` を結合して `index.html` を作る。`index.html` は直接編集しない） |
| 値の一覧を更新 | `node tobatoban/tools/dump-values.mjs`（`VALUES.md` を再生成） |

three.js は CDN（jsDelivr, r160）から読み込みます。P2P通信のライブラリ `trystero-nostr.js` は同じフォルダに置いています。

## 通信方式（なぜこの形にしたか）

参考にした「駅前ネコ大決戦」と同じく、**GitHub Pages ＋ Trystero（Nostrの公開リレーで相手を見つけ、WebRTCで直接つなぐ）**を使います。Claude Code もアカウントも不要で、URLと合言葉だけで入れます。

そのうえで、より良い形として次の点を変えました。

- **ホスト権威**：部屋を作った人の端末だけが戦闘（60Hz）を進め、参加者は入力（移動方向・ボタンの押下/離上・注目対象）だけを送ります。HP・ダメージ・ボスの行動・勝敗はホストが確定します。各端末が自分の状態を言い合う方式では起きやすい「HP不一致」「二重ダメージ」を構造的に防ぎます。
- **重複・再送に強い入力**：ボタン操作は連番つきで直近16件を毎回送り、ホストは番号で一度だけ処理します（必殺のゲージ消費も承認時に1回）。
- **参加者側の表示**：状態は約15回/秒で届き、100msの補間で滑らかに表示。自分の移動だけは手元で予測し、ホストの位置との差を少しずつ補正します。
- **切断**：参加者が抜けたキャラはAIが引き継ぎます。ホストが抜けた場合は中断画面を出します（ホスト移行・再接続は未実装）。
- **claude.ai のアーティファクトで開いた場合**：同じ組織のメンバーどうしなら claude.ai の room 機能（presence）で同じ方式の通信をします。ログインしない友だちには上の GitHub Pages のURLを案内します。

専用サーバー（例：Cloudflare Durable Objects）を置けば、WebRTCがつながりにくい回線（TURNが必要な環境）でも確実に遊べるようになりますが、運営者のアカウントとサーバー設定が必要なため、この初版では採用していません。

注意：協力プレイ中はホストの画面を前面にしておいてください（ブラウザが裏に回るとホストの処理が止まり、6秒で参加者側が中断扱いになります）。

## 実装済み

- キャラ選択10体・4体編成・X/Y入れ替え・アイテム2枠の持ち込み
- ソロ（操作1体＋AI3体）：通り（札小僧2波）→ 結界解除 → 祭り広場 → 登場演出（4.5秒・ソロはスキップ可）→ ボス戦 → 撃破/全滅/時間切れ → リザルト・再挑戦・編成変更
- むずかしさは「通常」の1つだけ（選択なし）。ボスの強さは旧「超」の能力値（ちから440・ようりょく500・まもり141）、体力は旧「超」の約70%。トバトーバンが与えるダメージはさらに30%減（ちから・ようりょくに0.7を掛ける。攻撃の速さ・回数・パターンはそのまま）
- ボス戦の祭り広場は28m×22.4m（初版の40m×32mから30%小さくした）
- AIが動かすキャラは、ちから・ようりょく・まもり・体力・移動速度がすべて90%（ソロで操作を交代すると、自分が動かすキャラは100%に戻る）
- 通常攻撃（三連30/30/60・単発・射撃）、ため技、回避、攻撃しながら後退、継続ダメージ印、隠密、受け流し反撃、渾身の一撃、麻痺のワナ、大庇護、ガード（ゲージ制）、反射ガード、呼び込み打ち、吸収、地雷（味方も巻き込む）、回復2種
- 必殺7型（40×10・60×8・100×4・400×1・250＋守り低下・味方強化・自己防御＋敵視・回復＋蘇生）。必殺中も世界は止まらず、他の人は操作を続けられる。自分のカットインは0.35秒、他人の必殺は短い通知だけ
- パッシブ10種、会心、属性（土に弱い・雷に強い）、敵視（ヘイト）、状態異常
- ボス技7種（札吹雪・しめ縄・提灯おとし・看板光線・張り手・千住大巡行・増援）。千住大巡行は狙った仲間を通る線を、横・斜め・縦など毎回ちがう向きから飛ぶ（前の2回と約30度以上ちがう向きを選び、横断の合間は広場の外周を回り込む）。HP1/3以下で計3回。次の技は距離・前後位置・HP段階・再使用制限から選ぶ（固定順ではない）
- 祭り灯籠4基（30秒以内に灯すとボスが6秒停止）。ソロは「合図→灯籠へ」でAIに依頼できる
- 気絶（30秒）と昇天の区別。救助は、気絶した仲間のまわりに出る緑の円に元気な仲間が入っている間ゲージがたまり、1人なら4秒で復活（HP 3分の1・ボタン不要。2人で入ると25%、3人で50%早い。円から出るとゲージはゆっくり減る。モミジ翁が円にいると基本2.7秒・HP50%）。AIの仲間は、気絶した仲間がいちばん近い敵より近くにいるときは救助を優先する。昇天済みは蘇生しない
- キャンディー：20秒ごとに、いま遊んでいる場所（通り／祭り広場）のどこかにランダムで1つ出る（最大3個）。取るとHP全回復（満タンの仲間は拾わない）。AIの仲間もHPが減ると取りにいく
- 全キャラの能力・攻撃の一覧：`CHARACTERS.md`（`node tools/dump-chars.mjs` で作り直す）
- Bダッシュとスタミナ、注目（ボスが飛ぶと解除、設定で着地後に自動で注目し直す）、カメラ回転・リセット
- HUD：仲間4体のカード、ボスHP（1/3の印）、自分のHP（遅れて減る帯）、必殺ゲージ、スタミナ、ミニマップ（実座標・番号・灯籠・予兆の輪と帯・気絶の×）、残り時間、画面外の矢印、頭上の番号と小さなHPバー、ダメージ数字と多段の合計。**HPの数値は表示しない**
- 横向き固定：縦長の画面では `#app` 全体を90度回転（左右どちらに倒すかは設定）。指の位置・セーフエリア・スクロールも回転後の向きに読み替える。実際に端末が横向きになったときは回転を外す
- 横画面（844×390基準）と縦画面（390×844基準・設定で横向き固定をOFFにしたとき）の別レイアウト、セーフエリア対応、ボタンの大きさ80〜130%（重要ボタンは最低48）、左右反転、スティック固定/追従
- カメラ：透視投影、俯角44度（ボスが遠いと最大8度浅く）、垂直FOV50度（縦は68度）、追従0.2秒、先読み1.5、足元をゲーム表示領域の70%（縦は64%）に置く、注目時はボスを3割寄せる、ゲートや鉄骨が隠すときは薄くする、他人の必殺でカメラを奪わない
- BGM（夕方の通り・祭り囃子調のボス戦・本気モード・勝敗ジングル）と技ごとの効果音（打撃・斬撃・光線・爆発・回復・ガード・ボスの各技・灯籠など）。音量設定あり
- 当たり判定は体の形で取る：ボスは脚2本と胴の下（ダウン中は倒れた胴も）、札小僧は紙の体。近接は体に触れたときだけ当たり、弾は体の表面で止まり、ダメージも当たった場所に出る。AIの仲間も体に触れる距離まで寄ってから攻撃する。ボスの張り手は手と衝撃波が届く範囲、千住大巡行は低く飛ぶ体の幅（飛ぶ向きに合わせて回転）、しめ縄は背後まで伸びる縄の範囲だけが当たる
- 先に進むときは足元に小さな黄色い矢印（結界が解けたら広場へ、遠くに敵が残っていればそちらへ）
- ソロ開始時に「仲間アイコンをタップで操作キャラを切り替え」を案内（アイコンが光る）
- 開発用の計測表示（攻撃ID・入力時刻・発生・各命中時刻・終了・再使用・ダメージ・状態倍率・相手の守り）
- 協力プレイ（2〜4人）：合言葉の部屋・ロビーでキャラ選択・ホスト権威の同期・ping表示・合図・切断時のAI引き継ぎ

- セーブ：「新しくアカウントを作る」でパスワード（4〜16文字・2回入力）だけを自分で決めると、ID（1〜10000）が作った順に自動で決まり、大きく表示される。次からはIDとパスワードでログインする。ゲームを開くたびにログイン画面が出る（ログインせずに遊ぶこともできるが、その場合はセーブされない）。ログイン中はタイトル・一時停止メニュー・アカウント画面の「セーブ」を押すだけで保存できる
- 自動セーブ：ログイン中は「戦いが終わったとき（勝ち・負け）」に自動で保存する。ログインせずに戦った記録は、同じ画面を開いている間にログインすればそのアカウントに足される
- 以前の形式（ID 1001〜）のセーブは、新しい版を開いたときに1回だけ消える
- セーブの中身：キャラごとのレベル・経験値・出撃回数・勝利回数・倒した敵の数、全体の戦績（出撃・勝利・倒した敵・最速クリア）、編成・アイテム・なまえ。戦闘の途中の状態は保存しない
- 保存先（GitHub版）：Firebase（プロジェクト `tobatoban-35633`）。IDは全員で通しの番号（Firestore の `meta/counter` を1つずつ進め、`ids/{番号}` に持ち主を記録）。パスワードの確認は Firebase Authentication（ID n は `p{n}@tobatoban.game` として登録）。セーブは `saves/{uid}` に本人だけが読み書きできる（`firestore.rules`）。どの端末でもID＋パスワードで続きから遊べる。パスワードは6文字以上
- 保存先（claude.ai のページ、または `?save=local`）：その端末のブラウザ（localStorage）。パスワードそのものは保存せず、IDとまぜたハッシュだけを持つ。番号は端末ごとの順番。別の端末へは「アカウント」画面の引き継ぎコード＋ID＋パスワードで移す
- 管理者が見る場所：Firebaseコンソールの Authentication →「ユーザー」（アカウントの一覧）と、Firestore →「データ」（次の番号・IDの持ち主・セーブ）
- レベル：10体とも Lv.1 から始まり、編成・ロビー・HUD・結果・アカウント画面に表示する（上がり方は今後決める。いまはレベルで能力は変わらない）

## 原作との関係・数値の扱い

- 能力値（レベル99・装備なし）、通常攻撃と必殺の威力・ヒット数、ボスの能力値は公開資料の値を使っています（`VALUES.md` の「資料で確認」）。ガード8秒・回復のため1.3秒などは攻略記事の目安（「資料の目安」）。
- 発生・持続・硬直・移動速度・ダメージ式・属性倍率・ゲージ増加量・カメラ・UI配置・通信周期などは**この初版の仮値**です。原作の測定値ではありません。
- **原作と一致したと確認できた項目はまだありません**（動画での測定を行っていないため）。`VALUES.md` で値ごとの状態を確認できます（ゲーム画面には出典を表示しません）。
- 体力は調整用データとして内部に持ち、画面には数値を出しません。
- 原作との主な差分：個体値の抽選なし、一時強化なし、灯籠のAI依頼、近くの敵へ自動で向く補助、必殺は通常の行動を中断して出せる、アイテムは4種の簡易版。

## 検査の実行

```
node tobatoban/tools/sim-test.mjs     # 21項目
node tobatoban/tools/net-test.mjs     # 往復100ms/200ms・重複30〜50%・欠落3〜5%
node tobatoban/tools/ai-battle.mjs normal 1
THREE_LOCAL=/path/to/three.module.js python3 tobatoban/tools/browser-check.py /tmp/shots
```

- 三連の命中時刻 0.15/0.45/0.85秒・硬直終了1.15秒、必殺の命中回数（10/8/4/1）、30/60/120fpsの描画ループで同じ入力ログを再生したときの命中数・総ダメージ・移動距離の一致を自動で確認しています。
- 360×800・390×844・800×360・844×390 で主要ボタンとHUDが重ならないこと、HUDにHPの数値が出ていないことを確認しています。
